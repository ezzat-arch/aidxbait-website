# Doctoory Website

Bilingual (English / Arabic, RTL) healthcare and e-commerce site: therapy services, a Shopify backed store, Paymob checkout, plus a JSON API that a separate mobile app consumes.

## Stack

- **Language / Runtime**: TypeScript 5 (strict), React 19, Node
- **Framework**: Next.js 15.2.6, App Router, all pages under `app/[locale]/`
- **Key dependencies**: Supabase (`@supabase/ssr` + `supabase-js`), next-intl 4, Tailwind 3.4 with shadcn/ui and Radix, Shopify Storefront GraphQL API, Paymob
- **Package manager**: npm (`package-lock.json` is the live lockfile)

## Rules

- Every user facing string is translated (both `messages/en.json` and `messages/ar.json`, read with `useTranslations`), every layout works in RTL, and links go through `@/i18n/navigation` rather than `next/link`. Details in [i18n/AGENTS.md](i18n/AGENTS.md).
- Four Supabase clients, one per context: `client.ts` (browser), `server.ts` (server components and actions), `admin.ts` (service role, server only, bypasses RLS), `middleware.ts` (session refresh). `admin.ts` must never reach client code.
- API routes always answer `{ success: boolean, data?, error? }` with a matching HTTP status, wrap the handler in try/catch, and log with a `[Area]` prefix and no secrets.
- Files use tabs, double quotes, and semicolons (Prettier settings live in `.vscode/settings.json`; there is no committed Prettier config).
- `components/ui/` is generated by shadcn/ui. Regenerate or extend around it rather than hand editing.
- Route handler and page params are Promises in Next.js 15. Always `await params`.
- Schema changes are numbered SQL files in `database/migrations/`, applied by hand in the Supabase SQL editor. There is no migration runner.

## Gotchas

- `next.config.mjs` sets `eslint.ignoreDuringBuilds` and `typescript.ignoreBuildErrors`, so a green `npm run build` does not mean the types are clean. Check types yourself with `npx tsc --noEmit`.
- Three lockfiles are committed. `package-lock.json` and `yarn.lock` track the current dependencies; `pnpm-lock.yaml` is stale from 2025 and should not be trusted.
- `middleware.ts` chains next-intl and Supabase. An auth redirect must never be merged onto next-intl's rewrite, or the response carries both `x-middleware-rewrite` and `Location` and serves a 404. The existing branch guards this.
